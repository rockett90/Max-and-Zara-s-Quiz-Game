Side-Scrolling Quiz Game
About the Project

This project is a side-scrolling game designed for children aged 4-10. It provides a fun and interactive way to engage with literacy and math questions in multiple languages. The goal is to create an exciting and competitive quiz experience within a simple side-scrolling environment.
Inspiration

This project is a work in progress, and future updates will include:

    New obstacles and environments
    Additional question sets for different subjects, difficulty levels and languages
